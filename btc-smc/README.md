# BTC 聪明钱信号台

BTC 永续 15 分钟的聪明钱（SMC）信号提醒页：出信号时响铃告诉你开多 / 开空和止损、止盈价，到价时再提醒平仓。盈亏比固定 1:2。只读公开行情，不需要账户和 API Key，不会替你下单。

和 gs-quant 本身没有关系，只是借这个仓库放文件并用 GitHub Pages 发布。

## 在手机上打开

1. 仓库 **Settings → Pages**：Source 选 **Deploy from a branch**，Branch 选放着本目录的分支，文件夹保持 **/ (root)**，点 **Save**。
2. 等一两分钟，打开 `https://<你的用户名>.github.io/gs-quant/btc-smc/`。
3. 在手机浏览器菜单里点「添加到主屏幕」，以后像 app 一样点图标打开。

手机锁屏或切到别的 app 后，系统会暂停页面，那段时间不会提醒。要么插着电、开着页面里的「保持屏幕常亮」放在旁边；要么让一台电脑一直开着这个页面，并在设置里配好 Telegram 推送。

## 规则

1. 价格在 EMA200 上方只做多，下方只做空。
2. 等价格扫掉一个明显的前低（做多）或前高（做空）。
3. 扫完 2 小时内，一根 15 分钟 K 线收盘确认结构转变，提醒开仓。
4. 止损在扫出来的极值外侧，止盈 = 2 倍止损距离。
5. 止损距离小于 0.25% 或大于 1.2% 的不做；24 小时没结果就平掉。

## 回测

Binance BTCUSDT 永续 15 分钟，2024-07-01 至 2026-11-09，已扣手续费和滑点：

| 档位 | 笔数 | 止盈 / 止损 / 超时 | 合计 | 平均每笔 | 最大回撤 |
|---|---|---|---|---|---|
| 严格（默认） | 112 | 42 / 52 / 18 | +19.0R | +0.17R | 8.9R |
| 标准 | 213 | 76 / 114 / 23 | +7.9R | +0.04R | 22.2R |

这不能当成稳定赚钱的证据。参数是在同一段数据上选出来的；对一个相近参数做的独立验证（2026 年，77 笔）结果是 −9.3R。扣费后大约在保本附近，优势没有被统计证实。不是投资建议。

复现：从 <https://data.binance.vision/data/futures/um/monthly/klines/BTCUSDT/15m/> 下载月度文件，解压后合并成一个 CSV，然后运行 `node backtest.js <klines.csv>`。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 发布的页面（由 `build.js` 生成，不要手改） |
| `app.src.html` | 页面源码 |
| `smc-engine.js` | 策略引擎，页面和回测共用同一份 |
| `build.js` | 把引擎内联进页面：`node build.js` |
| `backtest.js` | 回测脚本 |
| `sw.js`、`manifest.webmanifest`、`icons/` | 手机通知和添加到主屏幕用 |
